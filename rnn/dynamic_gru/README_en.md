# DynamicGRU

English | [简体中文](./README.md)

DynamicGRU is a single-layer, unidirectional GRU (gated recurrent unit) forward full-loop operator: one call completes, for all time steps, the two-gate GEMM, the candidate-gate GEMM, and the element-wise gated update. It outputs the step-wise hidden state `y`, the final-step hidden state `output_h`, and the three gate activations `r`/`i`/`n`. It also absorbs the variable-length sequence masking capability of RnnGenMaskV2 (passing `seq_length` activates this capability, and mask generation and frozen-style application are completed inside the operator).

> This operator does not provide an aclnn single-operator interface (neither the operator project nor the installation package contains `op_api/`). The invocation path is GEIR / GE graph mode (see [Invocation Description](#invocation-description) and [Invocation sample](examples/test_geir_dynamic_gru.cpp)); on the PyTorch side, you can call it in graph mode through the TorchAir GE raw op.

## Function

- Operator function: performs the forward full-loop computation of a single-layer, unidirectional GRU (CANN DynamicGRU V1 semantics: reset gate placed before the candidate gate, `w` holding the joint two-gate weights in column order [r, i], and `cw` holding the candidate weights split independently), and internalizes the seqlength fusion rule semantics of "original length → mask → frozen-style application".
- Computation formula (for each time step t; σ is sigmoid, ⊙ is element-wise multiplication, and [·;·] is column concatenation):

  $$
  gates_t = [\,x_t\,;\,h_{t-1}\,]\cdot w + b_{[0:2H]}
  $$

  $$
  r_t = \sigma(gates_t[:,\,0:H]),\qquad i_t = \sigma(gates_t[:,\,H:2H])
  $$

  $$
  n_t = \tanh([\,x_t\,;\,r_t \odot h_{t-1}\,]\cdot cw + cb_{[0:H]})
  $$

  $$
  h_t = (h_{t-1} - n_t)\odot i_t + n_t
  $$

  When `seq_length` is provided, a 0/1 mask is generated by $mask_t[b] = (t < seq\_length[b])$ and applied in a frozen manner: $h_t = h_{t-1} + (h_t - h_{t-1})\odot mask_t$ (the hidden state at padding steps is frozen at the boundary value, and `r`/`i`/`n` are not affected by the mask); `y_t = h_t`, and `output_h` is the hidden state of the final step (at the valid length boundary when the mask is activated).
- Numerical specification: the multiply-add operations of the two GEMMs accumulate in fp32, and sigmoid/tanh are computed in fp32 and then cast back to the output dtype.

## Parameters

| Parameter name | Input/Output/Attribute | Description | Data type | Data format |
|--------|----------------|------|----------|----------|
| x | Input | Time-step input sequence (num_step, batch_size, input_size), time_major | FLOAT16 | ND |
| w | Input | Joint weights of the r/i two gates [input_size+hidden_size, 2*hidden_size], output column order [r, i] | FLOAT16 | ND |
| b | Input | Two-gate bias (1D, length no less than 2*hidden_size and aligned to 16, valid values are the first 2*hidden_size ones); must have the same dtype as cb | FLOAT16, FLOAT | ND |
| cw | Input | Candidate gate weights [input_size+hidden_size, hidden_size] | FLOAT16 | ND |
| cb | Input | Candidate gate bias (1D, length no less than hidden_size and aligned to 16, valid values are the first hidden_size ones); must have the same dtype as b | FLOAT16, FLOAT | ND |
| seq_length | Optional input | Real sequence length per batch [batch_size], value range 0 ≤ s[b] ≤ num_step; passing it activates the mask capability, and the default is fixed-length behavior | INT32 | ND |
| init_h | Optional input | Initial hidden state (hidden_size, batch_size); when it is absent, the first-step h is set to zero; must have the same dtype as b/cb | FLOAT16, FLOAT | ND |
| y | Output | Step-wise hidden state (num_step, hidden_size, batch_size), y_t = h_t (frozen h_t when the mask is activated); dtype follows b/cb | FLOAT16, FLOAT | ND |
| output_h | Output | Final-step hidden state, written back step by step with the same shape as y (hidden state at the valid length boundary when the mask is activated); dtype follows b/cb | FLOAT16, FLOAT | ND |
| r | Output | Reset gate activation σ(·), value range (0, 1), not affected by the mask; dtype follows b/cb | FLOAT16, FLOAT | ND |
| i | Output | Update gate activation σ(·), value range (0, 1), not affected by the mask; dtype follows b/cb | FLOAT16, FLOAT | ND |
| n | Output | Candidate gate activation tanh(·), value range (-1, 1), not affected by the mask; dtype follows b/cb | FLOAT16, FLOAT | ND |
| direction | Attribute | Direction, default "UNIDIRECTIONAL", only this value is supported (bidirectional requires two calls, one per direction) | String | - |
| cell_depth | Attribute | Cell depth, default 1, only 1 is supported (placeholder attribute) | Int | - |
| keep_prob | Attribute | Dropout keep rate, default 1.0, only 1.0 is supported (placeholder attribute, no dropout) | Float | - |
| cell_clip | Attribute | Cell clipping, default -1.0, only -1.0 is supported (placeholder attribute, no clipping) | Float | - |
| num_proj | Attribute | Projection dimension, default 0, only 0 is supported (placeholder attribute, no projection) | Int | - |
| time_major | Attribute | Time-major layout, default true, only true is supported | Bool | - |
| activation | Attribute | Activation function, default "tanh", only "tanh" is supported | String | - |
| is_training | Attribute | Training-state flag, default true, both true and false are allowed (placeholder attribute, forward semantics does not distinguish) | Bool | - |

In total, 2 supported dtype combinations exist: `x`/`w`/`cw` are always FLOAT16, and `seq_length` is always INT32; the difference lies only in `b`/`cb` (and `init_h` plus all outputs that follow its dtype), which can be FLOAT16 or FLOAT32.

## Constraints

- Hard shape constraints: `w.shape[0] == x.shape[2] + cw.shape[1]`; `w.shape[1] == 2 * cw.shape[1]`; `cw.shape == (input_size+hidden_size, hidden_size)`; `x.shape[1] == seq_length.shape[0] == init_h.shape[1]`; `init_h.shape[0] == cw.shape[1]`; the shapes of all 5 outputs are equal to (L, H, N). No numpy-style broadcasting exists among inputs.
- dtype constraints: only the preceding 2 combinations are supported; `b` and `cb` must have the same dtype, and `init_h` and all outputs must have the same dtype as `b`/`cb`.
- Data format: all inputs and outputs support only ND.
- Alignment constraints: the length of `b` is no less than 2H and aligned to 16; the length of `cb` is no less than H and aligned to 16.
- Empty tensor: when K = 0 (I = 0 and H = 0), the outputs are empty tensors; when L = 0 or N = 0, the outputs are naturally empty; the non-empty path requires input_size I > 0.
- Special values: the entry does not reject NaN/Inf — NaN propagates along time, ±Inf saturates the gate activations, and the outputs are bounded.
- Determinism: time steps recurse strictly serially without atomic writes, so multiple executions with the same input on the same device produce bitwise identical results.
