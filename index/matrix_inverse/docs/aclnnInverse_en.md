## Function

- Description: Computes the inverse matrix of the input square matrix.
- Formula:

  $$
  {A}^{-1}A = A{A}^{-1} = {I}_{n}
  $$

  Where $A$ is the input tensor, $A^{-1}$ is the inverse of $A$, and $I_n$ is the $n$-dimensional identity matrix.

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnInverseGetWorkspaceSize" first to obtain the workspace size required for computation and the executor containing the operator computation process. Then call "aclnnInverse" to perform the computation.

```Cpp
aclnnStatus aclnnInverseGetWorkspaceSize(
    const aclTensor* self,
    aclTensor*       out,
    uint64_t*        workspaceSize,
    aclOpExecutor**  executor)
```

```Cpp
aclnnStatus aclnnInverse(
    void*          workspace,
    uint64_t       workspaceSize,
    aclOpExecutor* executor,
    aclrtStream    stream)
```
