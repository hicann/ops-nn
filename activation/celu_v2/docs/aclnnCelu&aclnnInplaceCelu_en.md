## Function

- Description: aclnnCelu computes the continuously differentiable exponential linear unit (CELU) activation function for each element x in input tensor self and stores the result in output tensor out. aclnnInplaceCelu computes the continuously differentiable exponential linear unit (CELU) activation function for each element x in input tensor selfRef and stores the result in input tensor selfRef.

- Formula:

$$
CELU(x) = max(0, x) + min(0, \alpha \ast (exp(x / \alpha) - 1))
$$

## Function Prototype

- aclnnCelu and aclnnInplaceCelu implement the same function. The differences in usage are as follows. Select the appropriate operator based on your actual scenario.

  - aclnnCelu: Create a new output tensor object to store the computation result.
  - aclnnInplaceCelu: No need to create a new output tensor object. The computation result is stored directly in the memory of the input tensor.

- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnCeluGetWorkspaceSize" or "aclnnInplaceCeluGetWorkspaceSize" first to obtain the workspace size required for computation and the executor that contains the operator computation flow. Then call "aclnnCelu" or "aclnnInplaceCelu" to perform the computation.
