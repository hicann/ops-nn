## Function

- Description: An activation function used to solve the problem that the ReLU function outputs 0 when the input is less than 0, preventing neurons from being unable to update parameters.
- Formula:

  $$
  out = max(0,self) + negativeSlope * min(0,self)
  $$

## Function Prototype

- aclnnLeakyRelu and aclnnInplaceLeakyRelu implement the same function. The differences are as follows. Select the appropriate operator based on your actual scenario.

  - aclnnLeakyRelu: A new output tensor object needs to be created to store the computation result.
  - aclnnInplaceLeakyRelu: No need to create a new output tensor object. The computation result is stored directly in the memory of the input tensor.

- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call the "aclnnLeakyReluGetWorkspaceSize" or "aclnnInplaceLeakyReluGetWorkspaceSize" API first to obtain the workspace size required for the computation and the executor that contains the computation process of the operator, and then call the "aclnnLeakyRelu" or "aclnnInplaceLeakyRelu" API to perform the computation.

## Constraints

- Deterministic computation:
  - aclnnLeakyRelu&aclnnInplaceLeakyRelu default to a deterministic implementation.

- If negativeSlope uses an integer type as the attribute input while the input self is of the FLOAT type, precision loss may occur when negativeSlope is greater than 2^24 or less than -2^24. Similarly, if the input self is of the FLOAT16 type, precision loss may occur when negativeSlope is greater than 2^11 or less than -2^11.

  CHECK_RET(ret == ACL_SUCCESS, LOG_PRINT("copy result from device to host failed. ERROR: %d\n", ret); return ret);
  for (int64_t i = 0; i < size; i++) {
    LOG_PRINT("result[%ld] is: %f\n", i, resultData[i]);
  }

  // 6. Release aclTensor and aclScalar. Modify the code based on the specific API definition.
  aclDestroyTensor(selfRef);
  aclDestroyScalar(negativeSlope);

  // 7. Release device resources. Modify the code based on the specific API definition.
  aclrtFree(selfRefDeviceAddr);
  if (workspaceSize > 0) {
    aclrtFree(workspaceAddr);
  }
  aclrtDestroyStream(stream);
  aclrtResetDevice(deviceId);
  aclFinalize();
  return 0;
}
