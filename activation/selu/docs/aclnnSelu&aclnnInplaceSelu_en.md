## Function

- Description: Applies the Selu activation function to the input tensor element-wise and outputs the result tensor.
- Formula:

  $$
  output_i = scale \cdot [\max(0, input_i) + \min(0, \alpha \cdot (\exp(input_i) - 1))] \\
  \alpha = 1.6732632423543772848170429916717 \\
  scale = 1.0507009873554804934193349852946
  $$

## Function Prototype

- aclnnSelu and aclnnInplaceSelu implement the same function. The differences in usage are as follows. Select the appropriate operator based on your actual scenario.
  - aclnnSelu: Creates a new output tensor object to store the computation result.
  - aclnnInplaceSelu: No need to create a new output tensor object. The computation result is stored directly in the memory of the input tensor.
- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). First call the "aclnnSeluGetWorkspaceSize" or "aclnnInplaceSeluGetWorkspaceSize" API to obtain input parameters and calculate the required workspace size according to the process. Then call the "aclnnSelu" or "aclnnInplaceSelu" API to perform the computation.
