## Function

- Description: Swish Gated Linear Unit (SwiGLU) activation function, which computes the SwiGLU of x.

- Formula:

  <p style="text-align: center">
  out<sub>i</sub> = SwiGlu(x<sub>i</sub>)=Swish(A<sub>i</sub>)*B<sub>i</sub>
  </p>
  where A<sub>i</sub> denotes the first half of the tensor obtained by splitting x<sub>i</sub> along the specified dim dimension, and B<sub>i</sub> denotes the second half of the tensor obtained by splitting x<sub>i</sub> along the specified dim dimension.

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). First call "aclnnSwiGluGetWorkspaceSize" to obtain the workspace size required for computation and an executor that contains the computation process of the operator, and then call "aclnnSwiGlu" to perform the computation.

```Cpp
aclnnStatus aclnnSwiGluGetWorkspaceSize(
  const aclTensor *x,
  int64_t          dim,
  const aclTensor *out,
  uint64_t        *workspaceSize,
  aclOpExecutor  **executor)
```

```Cpp
aclnnStatus aclnnSwiGlu(
  void           *workspace,
  uint64_t        workspaceSize,
  aclOpExecutor  *executor,
  aclrtStream     stream)
```

  // Calculate the strides of the contiguous tensor.
  std::vector<int64_t> strides(shape.size(), 1);

    strides[i] = shape[i + 1] * strides[i + 1];

  // Call the aclCreateTensor API to create an aclTensor.
  *tensor = aclCreateTensor(shape.data(), shape.size(), dataType, strides.data(), 0, aclFormat::ACL_FORMAT_ND,
                            shape.data(), shape.size(), *deviceAddr);
  return 0;
}
