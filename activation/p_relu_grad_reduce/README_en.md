## Function

- Operator function: Sums the intermediate result `updates` generated by PReluGradUpdate over the broadcast dimensions of `weights` relative to `features`, and outputs the weight gradient `da`.
- Formula: `da = ReduceSum(updates, axes)`; `axes` are the dimensions along which `weights` is broadcast-expanded in `features`. For a scalar weight, the sum is over all dimensions.
- The elements of `updates` are computed by PReluGradUpdate from `features` and `grads`; this operator only performs the reduction, and does not compute `gradInput` or generate `updates`.
