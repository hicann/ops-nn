|  <term>Atlas training products</term>    |     √    |

## Function

- Operator function: An activation function. When the value in the tensor is greater than 0, the value itself is taken; when the value is less than 0, the product of the weight and the value is taken.

- Formula:

$$out_i=\mathrm{PRelu}(x_i)=\max(0, x_i) + weight \times \min(0, x_i)$$
