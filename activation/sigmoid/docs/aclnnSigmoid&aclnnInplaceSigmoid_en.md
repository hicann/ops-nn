## Function

- Description: Performs the Sigmoid operation on the input tensor.

- Formula:

$$
out = {\frac{1} {1+{e}^{-input}}}
$$

## Function Prototype

- aclnnSigmoid and aclnnInplaceSigmoid implement the same function. The differences in usage are as follows. Select the appropriate operator based on your actual scenario.
  - aclnnSigmoid: Create a new output tensor object to store the computation result.
  - aclnnInplaceSigmoid: No need to create a new output tensor object. The computation result is stored directly in the memory of the input tensor.
- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnSigmoidGetWorkspaceSize" or "aclnnInplaceSigmoidGetWorkspaceSize" first to obtain the input parameters and calculate the required workspace size based on the computation flow. Then call "aclnnSigmoid" or "aclnnInplaceSigmoid" to perform the computation.
