## Function

- Operator function: the reduce-grad stage of the batch normalization training backward pass (Batch Normalization Training Reduce Grad). Given the upstream gradient `grads`, the forward input `x`, the per-channel statistics `diff_scale`/`diff_offset` produced by BNTrainingUpdateGrad, and `scale`/`batch_mean`/`batch_variance`, the operator computes the gradient `y` to be backpropagated to `x`. In the GE graph, this operator is generated by the fused expansion of `FusedBatchNormGrad`, and it is used together with BNTrainingUpdateGrad.

- Formula:

  Let the shape of grads be [N, C, R...] (dim0 is N, dim1 is C, and the trailing dimensions are flattened into R). num = N * R:

  $$
  sqrtVar = \sqrt{batch\_variance + ε}
  $$

  $$
  multiplier = {diff\_scale * (-{1\over num})\over sqrtVar}
  $$

  $$
  addend = {batch\_mean\over sqrtVar} * {diff\_scale\over num} + diff\_offset * (-{1\over num})
  $$

  $$
  mulScale = {scale\over sqrtVar}
  $$

  $$
  y = ((grads + multiplier * x) + addend) * mulScale
  $$

  `multiplier`/`addend`/`mulScale` are all vectors of length C and are broadcast along the C dimension. fp16/bf16 inputs are upcast to fp32 inside the operator for computation, and the results are written back with a single rounding.

## Parameters

| Parameter name | Input/Output/Attribute | Description | Data type | Data format |
|---|---|---|---|---|
| grads | Input | The gradient tensor backpropagated from the upper layer. The shape is [N, C, R...], and dimensions ≥ 2 are supported. dim0 is N, dim1 is C, and the trailing dimensions are flattened into the normalization axis R. Empty tensors are not supported (each dimension must be positive). | FLOAT32, FLOAT16, BFLOAT16 | ND |
| x | Input | The forward input tensor. Its shape and data type are both consistent with `grads`. | FLOAT32, FLOAT16, BFLOAT16 | ND |
| diff_scale | Input | The per-channel statistic (the scale gradient output of BNTrainingUpdateGrad), shape [C]. The number of elements must equal dim1 of grads. | FLOAT32 | ND |
| diff_offset | Input | The per-channel statistic (the offset gradient output of BNTrainingUpdateGrad), shape [C]. The number of elements must equal dim1 of grads. | FLOAT32 | ND |
| scale | Input | The per-channel scale factor, shape [C]. The number of elements must equal dim1 of grads. | FLOAT32 | ND |
| batch_mean | Input | The forward per-channel mean, shape [C]. The number of elements must equal dim1 of grads. | FLOAT32 | ND |
| batch_variance | Input | The forward per-channel variance, shape [C]. The number of elements must equal dim1 of grads. | FLOAT32 | ND |
| epsilon | Optional attribute | The small value added to batch_variance before the square root is taken. The default value is 0.0001. | FLOAT32 | - |
| y | Output | The gradient backpropagated to x. Its shape and data type are both consistent with `grads`. | FLOAT32, FLOAT16, BFLOAT16 | ND |

## Constraints

- The dtype and shape of `grads` must be consistent with `x`. The five statistics are always FLOAT32, and their element counts equal C.
- Empty tensors are not supported (num = N*R is the denominator of the formula; if any dimension is 0, division by zero occurs, and this is structurally rejected in the tiling stage).
- `batch_variance + epsilon` must be positive (the domain of the square root). The operator performs no additional guarding against illicit statistics, consistent with the A2 behavior.
