## Function

- Description: The GemmaRmsNorm operator is a normalization operation commonly used in large models. Compared with the RmsNorm operator, it performs a +1 operation on gamma during computation.
- Formula:

  $$
  \operatorname{GemmaRmsNorm}(x_i)=\frac{1}{\operatorname{Rms}(\mathbf{x})} * x_i * (1 + gamma_i), \quad \text { where } \operatorname{Rms}(\mathbf{x})=\sqrt{\frac{1}{n} \sum_{i=1}^n x_i^2+epsilon}
  $$

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call `aclnnGemmaRmsNormGetWorkspaceSize` first to obtain the workspace size required for the computation and the executor that contains the operator computation process, and then call `aclnnGemmaRmsNorm` to perform the computation.

```Cpp
aclnnStatus aclnnGemmaRmsNormGetWorkspaceSize(
  const aclTensor *x,
  const aclTensor *gamma,
  double           epsilon,
  const aclTensor *yOut,

```

## Constraints

- Functional dimensions:
  - Supported data types:
    - x, gamma, and yOut support FLOAT32, FLOAT16, and BFLOAT16.
    - rstdOut supports FLOAT32.
  - Supported [data format](../../../docs/en/context/data_format.md): ND.
- Unsupported type description:

  DOUBLE: The instruction does not support DOUBLE.

- Boundary value scenario description:
  - When the input is Inf, the output is Inf.
  - When the input is NaN, the output is NaN.
- Supported data types by platform:

    | `x` Data Type | `gamma` Data Type | `yOut` Data Type | `rstdOut` Data Type |
    | -------- | -------- | -------- | -------- |
    | FLOAT16 | FLOAT16 | FLOAT16 | FLOAT32 |
    | BFLOAT16 | BFLOAT16 | BFLOAT16 | FLOAT32 |
    | FLOAT32 | FLOAT32  | FLOAT32 | FLOAT32  |

- Deterministic computation:
  - aclnnGemmaRmsNorm defaults to a deterministic implementation.
