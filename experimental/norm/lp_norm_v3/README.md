## 功能说明

- 算子功能：实现张量的 Lp 范数计算与归一化功能，支持对输入张量按指定维度计算 p 范数，并使用对应范数对输入进行归一化。
- 支持全局、按行、按列三种计算模式。

- 计算公式：

设输入张量为 \(x\)，范数阶数为 \(p\)。实现固定使用 \(\epsilon=10^{-6}\) 作为数值稳定项，该值不是可配置属性。

- **Lp 范数计算：**

$$
\text{norm} = \left( \sum |x_i|^p + \epsilon \right)^{1/p}
$$

- **归一化结果：**

$$

y_i = \frac{x_i}{\text{norm}}

$$
其中，范数的计算范围由 `axis` 参数决定：`axis=-1`（默认值）对全量输入计算一个范数，`axis=0` 按行计算，`axis=1` 按列计算。`axis=0` 和 `axis=1` 仅支持二维输入 `[rows, cols]`。归一化结果按对应的全局、行或列范数进行逐元素相除。

## 参数说明

| 参数名 | 输入/输出/属性 | 描述 | 数据类型 | 数据格式 |
|------|---------------|------|---------|---------|
| x | 输入 | 待进行 LpNormV3 计算的输入张量 | FLOAT、FLOAT16 | ND |
| p | 属性 | Lp 范数的阶数 | FLOAT | - |
| axis | 属性 | 范数计算方式：-1（默认，全局），0（按行），1（按列）；0/1 仅支持二维输入 | INT | - |
| y | 输出 | 归一化后的输出张量 | FLOAT、FLOAT16 | ND |
