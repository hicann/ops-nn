## Function

- Operator function: Updates model parameters during gradient descent training.

- Formula:

  $$
  var = var - alpha \times delta
  $$

  Here, var denotes the model parameters to be updated, alpha denotes the learning rate, and delta denotes the gradient of the parameters.
