## Function

- Description: Performs a rounding operation with the specified precision on each tensor in the input tensor list. The rounding mode is specified by roundMode. Compared with [aclnnForeachRoundOffNumber](aclnnForeachRoundOffNumber.md), this API changes the structure type of the input parameter roundMode from aclTensor to aclScalar. Select an appropriate API based on actual requirements.
- Formula:

  $$
  x = [{x_0}, {x_1}, ... {x_{n-1}}]\\
  y = [{y_0}, {y_1}, ... {y_{n-1}}]\\
  $$

  $$
  y_i = round(x_i, roundMode) (i=0,1,...n-1)
  $$

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call the "aclnnForeachRoundOffNumberV2GetWorkspaceSize" API first to obtain the workspace size required for the calculation and the executor that includes the calculation process of the operator, and then call the "aclnnForeachRoundOffNumberV2" API to perform the calculation.
