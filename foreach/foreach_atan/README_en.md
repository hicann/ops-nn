## Function

- Operator function: Performs the arctangent function computation element-wise.
- Formula:

  $$
  x = [{x_0}, {x_1}, ... {x_{n-1}}]\\
  y = [{y_0}, {y_1}, ... {y_{n-1}}]\\
  $$

  $$
  {\rm y}_i = \tan^{-1}(x_i) (i=0,1,...n-1)
  $$
