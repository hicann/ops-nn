## Function

- Description: Performs exponentiation on each tensor in the input tensor list x, with the exponent being the corresponding scalar in the scalar list exponent.

- Formula:

  $$
  x = [{x_0}, {x_1}, ... {x_{n-1}}]\\
  exponent = [{exponent_0}, {exponent_1}, ... {exponent_{n-1}}]\\
  y = [{y_0}, {y_1}, ... {y_{n-1}}]\\
  $$

  $$
  y_i = {{x_i}}^{exponent_i} (i=0,1,...n-1)
  $$

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnForeachPowScalarListGetWorkspaceSize" first to obtain the workspace size required for the computation and the executor containing the operator computation process, and then call "aclnnForeachPowScalarList" to perform the computation.

```Cpp
  const aclTensorList *out,
  uint64_t            *workspaceSize,

```
