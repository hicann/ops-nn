## Function

- Operator function: performs the reciprocal operation on each tensor of the input tensor list.
- Formula:

  $$
  x = [{x_0}, {x_1}, ... {x_{n-1}}]\\
  y = [{y_0}, {y_1}, ... {y_{n-1}}]\\
  $$

  $$
  y_i = \frac{1}{{x_i}} (i=0,1,...n-1)
  $$

## Constraints

- Support for non-contiguous output tensors: aclnnForeachReciprocal supports non-contiguous output tensors (the operator automatically converts them to contiguous internally and writes the result back). The graph mode (IR) does not support non-contiguous output tensors.
