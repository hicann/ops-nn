## Function

- Operator function: performs the square root operation on each tensor of the input tensor list.
- Formula:

  $$
  x = [{x_0}, {x_1}, ... {x_{n-1}}]\\
  y = [{y_0}, {y_1}, ... {y_{n-1}}]\\
  $$

  $$
  y_i =\sqrt{x_i} (i=0,1,...n-1)
  $$
