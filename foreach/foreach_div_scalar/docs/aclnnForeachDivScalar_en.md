## Function

- Description: Divides each tensor in the tensor list x by the tensor scalar.

- Formula:

  $$
  x = [{x_0}, {x_1}, ... {x_{n-1}}]\\
  y = [{y_0}, {y_1}, ... {y_{n-1}}]\\
  $$

  $$
  {\rm y}_i = \frac{x_i}{{\rm scalar}} (i=0,1,...n-1)
  $$

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnForeachDivScalarGetWorkspaceSize" first to obtain the workspace size required for the calculation and the executor that contains the calculation process of the operator, and then call "aclnnForeachDivScalar" to perform the calculation.

```Cpp
aclnnStatus aclnnForeachDivScalarGetWorkspaceSize(
  const aclTensorList *x,
  const aclTensor     *scalar,
  const aclTensorList *out,
  uint64_t            *workspaceSize,
  aclOpExecutor      **executor)
```

```Cpp
aclnnStatus aclnnForeachDivScalar(

  uint64_t       workspaceSize,
  aclOpExecutor *executor,
```
