## Function

- Description: Divides tensor list x by scalar scalar. Compared with [aclnnForeachDivScalar](aclnnForeachDivScalar.md), this API changes the structure type of the input parameter scalar from aclTensor to aclScalar. Select an appropriate API based on actual requirements.
- Formula:

  $$
  x = [{x_0}, {x_1}, ... {x_{n-1}}]\\
  y = [{y_0}, {y_1}, ... {y_{n-1}}]\\
  $$

  $$
  {\rm y}_i = \frac{x_i}{{\rm scalar}} (i=0,1,...n-1)
  $$

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call the "aclnnForeachDivScalarV2GetWorkspaceSize" API first to obtain the workspace size required for the computation and the executor that contains the computation flow, and then call the "aclnnForeachDivScalarV2" API to perform the computation.

```Cpp
aclnnStatus aclnnForeachDivScalarV2GetWorkspaceSize(
  const aclTensorList *x,
  const aclScalar     *scalar,
  aclTensorList       *out,
  uint64_t            *workspaceSize,
  aclOpExecutor      **executor)
```
