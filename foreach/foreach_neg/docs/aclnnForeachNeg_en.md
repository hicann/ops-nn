## Function

- Description: Computes the opposite number of each tensor in the input tensor list.

- Formula:

  $$
  x = [{x_0}, {x_1}, ... {x_{n-1}}]\\
  y = [{y_0}, {y_1}, ... {y_{n-1}}]\\
  $$

  $$
  y_i = -x_i (i=0,1,...n-1)
  $$

When the input data type is an integer type, the API result is consistent with `torch._foreach_neg`, with wraparound based on the bit width of the output data type. For example, when `INT16` input is `-32768`, the output is still `-32768`; when `INT8` input is `-128`, the output is still `-128`; when `UINT8` input is `1`, the output is `255`.

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnForeachNegGetWorkspaceSize" first to obtain the workspace size required for computation and the executor containing the computation process, and then call "aclnnForeachNeg" to execute the computation.

```Cpp
  const aclTensorList *x,
  const aclTensorList *out,
  uint64_t            *workspaceSize,
  aclOpExecutor      **executor)
```

## Constraints

- The number of tensors in x and out must be the same.
- All tensors in x must have the same data type, and the data type must be supported as described in the parameter table.
- The data type of the tensor at the corresponding position in out must be the same as that of x.
- The dimensions of each tensor in x/out must be in the range [0, 8].
- The shape of the tensor at the corresponding position in out must be the same as that in x.
- Empty tensors (0 elements) are supported.
- Non-contiguous tensors are supported for both x and out. When a tensor is non-contiguous, the API converts it to a contiguous tensor for computation and writes the result back.
- Deterministic computation:
  - aclnnForeachNeg defaults to a deterministic implementation.

```Cpp
  *tensor = aclCreateTensor(shape.data(), shape.size(), dataType, strides.data(), 0, aclFormat::ACL_FORMAT_ND,
                            shape.data(), shape.size(), *deviceAddr);
  return 0;
}
```
