## Function

- Operator function: performs the power operation (base x1, exponent x2) on each tensor of the input tensor list.
- Formula:

  $$
  x1 = [{x1_0}, {x1_1}, ... {x1_{n-1}}]\\
  x2 = [{x2_0}, {x2_1}, ... {x2_{n-1}}]\\
  y = [{y_0}, {y_1}, ... {y_{n-1}}]\\
  $$

  $$
  y_i = x1_i^{x2_i}  (i=0,1,...n-1)
  $$

## Constraints

- The output does not support non-contiguous tensors.
