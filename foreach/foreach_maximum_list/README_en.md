## Function

- Operator function: Performs element-wise comparison on the tensor list x1 and the tensor list x2, and computes the maximum value for each element.
- Formula:

  $$
  x1 = [{x1_0}, {x1_1}, ... {x1_{n-1}}], x2 = [{x2_0}, {x2_1}, ... {x2_{n-1}}]\\
  y = [{y_0}, {y_1}, ... {y_{n-1}}]\\
  $$

  $$
  {\rm y}_i = \max(x1_i, x2_i) (i=0,1,...n-1)
  $$

- The output does not support non-contiguous tensors.
