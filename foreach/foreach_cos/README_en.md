## Function

- Operator function: performs the cosine function element-wise.
- Formula:

  $$
  x = [{x_0}, {x_1}, ... {x_{n-1}}]\\
  y = [{y_0}, {y_1}, ... {y_{n-1}}]\\
  $$

  $$
  {\rm y}_i = \cos(x_i) (i=0,1,...n-1)
  $$
