## Function

- Description: Performs element-wise subtraction on elements in two tensor lists, and adjusts the subtraction coefficient using the alpha parameter.
  Compared with [aclnnForeachSubList](aclnnForeachSubList.md), this API changes the structure type of the input parameter alpha from aclTensor to aclScalar. Choose an appropriate API based on the actual requirements.
- Formula:

  $$
  x1 = [{x1_0}, {x1_1}, ... {x1_{n-1}}]\\
  x2 = [{x2_0}, {x2_1}, ... {x2_{n-1}}]\\
  y = [{y_0}, {y_1}, ... {y_{n-1}}]\\
  $$

  $$
  y_i = x1_i-{x2_i}*alpha (i=0,1,...n-1)
  $$

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call the "aclnnForeachSubListV2GetWorkspaceSize" API first to obtain the workspace size required for computation and the executor that contains the operator computation process, and then call the "aclnnForeachSubListV2" API to perform the computation.

## Constraints

- The tensor counts of `x1`, `x2`, and `out` must be identical.
<!-- npu="950" id7 -->
- <term>Ascend 950PR&950DT products</term>: The count of tensors in any single tensor list of `x1`, `x2`, and `out` shall not exceed 256.
<!-- end id7 -->
- When `x1`, `x2`, and `out` are all empty tensor lists, the API returns success without performing computation. Other tensor count mismatches return a parameter error.
- The `-1` (dynamic dimension) and `-2` (dynamic rank) markers are handled by Host inference according to the framework conventions. Tiling requires concrete shapes and non-negative element counts.
- Integer overflow wraps according to the bit width of the output data type.
- Deterministic computation:
  - aclnnForeachSubListV2 defaults to a deterministic implementation.
