## Function

- Description: Adds elements in two tensor lists one by one, and the addition coefficient can be adjusted through the alpha parameter. Compared with [aclnnForeachAddList](aclnnForeachAddList.md), this API changes the type of the input parameter alpha from aclTensor to aclScalar. Select an appropriate API based on actual requirements.
- Formula:

  $$
  x1 = [{x1_0}, {x1_1}, ... {x1_{n-1}}], x2 = [{x2_0}, {x2_1}, ... {x2_{n-1}}]\\
  y = [{y_0}, {y_1}, ... {y_{n-1}}]\\
  $$

  $$
  y_i = x1_i + x2_i * alpha (i=0,1,...n-1)
  $$

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call the "aclnnForeachAddListV2GetWorkspaceSize" API first to obtain the workspace size required for the computation and the executor containing the computation process of the operator, and then call the "aclnnForeachAddListV2" API to execute the computation.
